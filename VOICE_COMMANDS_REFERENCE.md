## 🎤 Voice Tips

### Speak Clearly
- Pause briefly before speaking
- Speak at normal pace
- Use clear pronunciation

### Wait for Status
- "Listening..." - Pixie is ready
- "Thinking..." - Processing your command
- "Searching..." - Looking up information
- "Answering..." - Speaking response

### If Not Recognized
- Speak louder or closer to mic
- Rephrase your command
- Check microphone permissions

## 🔧 Troubleshooting

### App Won't Open
```
Try: "Open [app name] web version"
Or: Check if app is installed
```

### Search Not Working
```
Try: Use "realtime search" instead
Or: Check internet connection
```

### Voice Not Recognized
```
Try: Check microphone in Windows settings
Or: Restart Pixie AI
```
